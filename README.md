# PIC Based Motor Controller
This was build to solve some problem in agricultural and urban areas in India - for domestic use only around 2010. The idea was to run pumps on a fixed time schedule daily. The device was built around the ATMEL PIC16F877A.
Coded on the HI-TECH C PRO for the PIC10/12/16 MCU family v9.65 which is now obsolete.
